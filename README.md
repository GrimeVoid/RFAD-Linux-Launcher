# RFAD Linux Launcher 2.0 (Native Python Edition)

Быстрый, чистый и безопасный лаунчер для сборки **Requiem For A Dream (Skyrim SE 6.2)** на Linux (CachyOS / Arch / Fedora / Ubuntu).

---

## Преимущества перед оригинальным Wails/Flatpak лаунчером

1. **Без Flatpak и без песочниц:** работает нативно в хост-системе. Видит все ваши диски, сокеты Wayland/X11, GameMode и MangoHud напрямую без вызовов `flatpak-spawn`.
2. **Нулевой хардкод путей:** автоматически и динамически определяет пути к префиксу Wine (`pfx`), `drive_c`, `ModOrganizer.exe` и исполняемым файлам Proton.
3. **Безопасная установка:**
   - Защита от выбора корневых папок (`_Games_` автоматически расширяется до `_Games_/RFAD`).
   - Проверка свободного места перед распаковкой (требуется от 75 ГБ).
   - Атомарная сборка: временные файлы изолированы в `.staging_extract`, при отмене или ошибке мусор не остаётся.
4. **Прямой запуск через Wine:** управление переменными окружения через `subprocess.Popen` без костыльных промежуточных bash-скриптов.
5. **Мгновенный отклик и лёгкость:** запускается за 0.1 секунды, потребляет всего ~30 МБ оперативной памяти (в отличие от WebKitGTK).
6. **Неблокирующий UI:** все тяжелые операции (распаковка, обновление, проверка) работают в изолированных потоках `QThread`.

## Структура проекта

```
rfad_launcher/
├── run.sh                  # Исполняемый скрипт быстрого запуска
└── src/
    ├── main.py             # Точка входа в приложение
    ├── config.py           # Конфигурация (~/.config/rfad-launcher/launcher.json)
    ├── core/
    │   ├── paths.py        # Умный резолвер путей (без хардкода)
    │   ├── runner.py       # Нативный запуск через Proton Wine
    │   ├── installer.py    # Безопасный установщик на базе innoextract
    │   ├── updater.py      # Проверка версий и патчинг
    │   └── mods.py         # Переключатели ReShade / ENB / CS / Steam DRM
    └── ui/
        ├── styles.py       # Тёмная тема (QSS)
        └── main_window.py  # Графический интерфейс на PyQt5
```

---

## Запуск

```bash
./run.sh
```
или:
```bash
python3 src/main.py
```
